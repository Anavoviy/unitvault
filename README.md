## 📖 О проекте

### Проблема

Юнит-экономика — это нервная система любого бизнеса. Но инструменты, которые используют фаундеры и продукт-менеджеры, редко соответствуют серьёзности задачи:

- **Excel / Google Sheets** — медленно пересчитывают сложные модели, не имеют версионирования, легко ломаются от случайного изменения ячейки.
- **Облачные сервисы** — требуют отправлять финансовые данные третьим лицам, что неприемлемо для многих компаний.
- **Специализированные SaaS** — дороги, избыточны для стартапа, часто не дают нужной гибкости в формулах.

В итоге: либо безопасность, либо удобство. Приходится выбирать.

### Решение

**UnitVault** — локальное desktop-приложение, которое сочетает инженерную точность с удобством современных инструментов.

- 🔒 **Local-first** — все данные хранятся только на вашем устройстве, зашифрованные на диске. Никогда не покидают компьютер.
- ⚡ **Мгновенные пересчёты** — изменение любого параметра обновляет все метрики и графики за <100ms благодаря реактивным сигналам Solid.js.
- 🎯 **Инженерная точность** — каждая формула покрыта тестами, все edge-cases (нулевой churn, деление на ноль, переполнение) явно обработаны.
- 🧩 **Гибкость** — поддержка SaaS, E-commerce, Marketplace и пользовательских формул.
